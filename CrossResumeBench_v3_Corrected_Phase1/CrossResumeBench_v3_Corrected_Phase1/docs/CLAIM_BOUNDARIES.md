# Claim Boundaries

After Phase 1 you may claim only what the artifacts establish.

Allowed if gate passes:
- a common real checkpoint boundary was captured and self-resumed in the tested versions;
- frozen MCC v2 safely transferred the common effect-ack continuation across the six directed pairs;
- ambiguous commit evidence caused conservative rejection.

Not allowed after Phase 1:
- universal cross-framework migration;
- all retry/parallel/callback boundaries are supported;
- official AAIF or CapLease systems were beaten;
- top-tier publication readiness;
- arbitrary Python instruction-pointer migration.
