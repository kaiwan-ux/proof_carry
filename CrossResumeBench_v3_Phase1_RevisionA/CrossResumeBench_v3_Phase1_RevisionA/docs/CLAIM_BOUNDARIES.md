# Claim Boundaries

A Phase1 Revision-A PASS supports only a narrow claim: frozen MCC v2 safely handles this external-commit two-world boundary across the tested native adapters and rejects observationally ambiguous cases.

It does **not** prove universal agent interoperability, all retry/parallel/approval semantics, official AAIF/CapLease superiority, cryptographic trust, LLM behavior, or arbitrary process migration.

CrewAI's source stop is a controlled failure immediately after a native method-completion checkpoint and before the acknowledgment side effect. MAF stops at a native superstep checkpoint. LangGraph stops using its checkpointed interrupt boundary.
