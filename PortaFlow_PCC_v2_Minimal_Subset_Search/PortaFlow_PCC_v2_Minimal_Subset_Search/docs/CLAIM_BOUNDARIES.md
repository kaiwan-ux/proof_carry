# Claim Boundaries
Allowed if supported by results:
- empirical minimal subset over the declared six component families;
- safe-completion/rejection/unsafe rates on the eight hold-out workflows;
- native confirmation across the three tested framework versions;
- comparison of explicit vs hybrid reconstruction.

Not allowed:
- universal mathematical minimality;
- arbitrary process/checkpoint binary interchange;
- universal agent-framework portability;
- state-of-the-art claims without external baselines/literature comparison;
- claiming rejected migrations were successful migrations.
