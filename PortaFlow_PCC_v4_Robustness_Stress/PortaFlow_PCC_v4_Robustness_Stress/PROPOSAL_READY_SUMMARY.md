# Proposal-ready experiment description

After freezing the minimal continuation representations discovered in earlier experiments, we perform a robustness stress test rather than adding more semantic fields. The test uses eight new workflow families and five pre-registered portable-evidence perturbations: clean evidence, irrelevant/duplicated history, out-of-order history, partial history loss, and contradictory effect evidence. Each case is executed over all six directed migration pairs among LangGraph, CrewAI, and Microsoft Agent Framework. The 1,200-run deterministic matrix separately measures safe completion, safe rejection, and unsafe continuation. The central hypothesis is that inference-guided history+receipts should tolerate normalizable event noise/order changes, fail closed when crucial history is missing, and reject contradictory commitment evidence rather than replaying irreversible effects. The compact explicit representation serves as a second frozen architecture and should be less sensitive to history corruption. No representation fields are tuned after results are observed.
