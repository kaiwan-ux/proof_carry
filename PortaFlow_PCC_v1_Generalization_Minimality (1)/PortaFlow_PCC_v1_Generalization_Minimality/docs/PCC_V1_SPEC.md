# PCC v1 semantic model under test

PCC v1 is a **candidate**, not a finalized standard.

Core candidate sections:

- application state
- semantic event history
- completed logical work
- retry counters
- runtime decisions
- loop counters
- control frontier
- pending obligations
- effect receipts
- continuation/dependency contract
- provenance (framework name and snapshot kind only)

Native checkpoint contents are excluded.

The purpose of this experiment is to discover which of these are redundant under strong reconstruction.
