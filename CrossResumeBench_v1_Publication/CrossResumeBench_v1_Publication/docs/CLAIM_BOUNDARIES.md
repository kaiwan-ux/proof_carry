# Claim boundaries
Allowed if supported by results: behavior-preserving continuation for the frozen benchmark cases; safe-rejection behavior under ambiguity; cross-runtime target execution on the tested versions.

Not allowed: arbitrary Python process migration; universal agent interoperability; direct native checkpoint loading across frameworks; proof that AAIF or CapLease themselves fail; state-of-the-art claims without official baseline integration; claims about stochastic LLM agents (v1 uses none).
