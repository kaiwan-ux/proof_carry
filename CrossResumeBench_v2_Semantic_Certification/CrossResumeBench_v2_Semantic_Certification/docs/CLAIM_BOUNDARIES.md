# Claim Boundaries

Allowed if results support them: schema-valid evidence transfer; target-side semantic reconstruction; safe rejection under unresolved effect or semantic-completion ambiguity; native source/target adapter execution on the tested framework versions.

Not allowed: direct loading of LangGraph checkpoints into CrewAI/MAF; arbitrary process migration; official superiority over AAIF or CapLease; universal coverage; LLM-agent claims.
