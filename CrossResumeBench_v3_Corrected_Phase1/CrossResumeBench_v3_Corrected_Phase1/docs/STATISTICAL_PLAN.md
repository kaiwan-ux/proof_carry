# Statistical Plan

Phase 1 is a correctness gate, not a significance study.

For full v3:
- base workflow cases are the primary experimental units;
- framework directions are paired repeated observations;
- report exact discordance tables per case/variant;
- compare MCC vs a competing baseline on paired outcomes (e.g. exact McNemar where applicable);
- report SCC, safe rejection, unsafe rate, and technical-failure rate with exact counts;
- never treat thousands of generated rows as thousands of independent scientific samples.
