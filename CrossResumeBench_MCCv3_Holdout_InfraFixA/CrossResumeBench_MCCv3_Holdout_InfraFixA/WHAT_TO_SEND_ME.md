# What to upload after running InfraFixA

If the native gate fails, upload:

`CrossResumeBench_MCCv3_Holdout_InfraFixA_NATIVE_GATE_diagnostics.zip`

If the native gate passes and the holdout completes, upload:

`CrossResumeBench_MCCv3_Holdout_InfraFixA_results.zip`

Do not send only screenshots. The ZIP contains the raw CSV/JSON artifacts needed to distinguish scientific failures from native-runtime failures.
