# Claim boundaries

If the experiment succeeds, it may support claims about **controlled hold-out continuation cases at declared safe migration points**.

Do not claim:

- universal migration of arbitrary agent programs,
- direct binary/native checkpoint interchange,
- mathematical minimality of PCC,
- state-of-the-art status without external baselines/literature comparison,
- stochastic LLM robustness,
- production exactly-once guarantees for arbitrary external services.

A 100% full-PCC score in this benchmark means sufficiency on the tested deterministic suite only.
