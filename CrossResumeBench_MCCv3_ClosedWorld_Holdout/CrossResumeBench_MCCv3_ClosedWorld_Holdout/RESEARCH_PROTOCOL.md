# Research Protocol

1. Verify MCC v3 mechanism hash and holdout suite hash.
2. Run 24 native family probes (8 families × 3 runtimes).
3. Run 96 native self-resume controls and 96 source captures.
4. Run the sealed 6,144 migration grid.
5. Evaluate external semantic-store equivalence against evaluator-only oracle truth.
6. Do not alter MCC v3 or the holdout after results.

Primary endpoint: MCC v3 unsafe continuation rate.
Secondary: safe completion coverage, safe rejection rate, pair consistency, family/variant breakdown, and comparison with frozen MCC v2 and concept-level baselines.
