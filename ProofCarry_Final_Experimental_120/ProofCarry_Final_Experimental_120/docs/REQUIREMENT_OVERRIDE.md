# Final Case-Count Override

An earlier requirements note in this project mentions 104 base cases. The final user instruction supersedes that number:

- **8 workflow families**
- **15 genuinely distinct base cases per family**
- **120 total base cases**

The frozen Expanded120 manifest and all run scripts use 120. The older 104-case wording is retained only inside the original requirements attachment for provenance and must not be interpreted as the final benchmark size.
