# Runtime-Specific Semantic Identity

The experiment deliberately does not use a single identifier across frameworks.

- LangGraph: `lg.node::<canonical>`
- CrewAI: `crew.task::<canonical>`
- Microsoft Agent Framework: `maf.activity::<canonical>`

A target contract names its target-native subject. Source evidence names the source-native subject. Both must be mapped to the same canonical semantic subject by approved, signed identity bindings. This makes the six directed runtime pairs semantically meaningful rather than label-only replications.

The runtime-specific labels are a controlled semantic-translation layer attached to real native pause/resume executions. They are not a claim that every version of each framework exposes these exact public field names.
