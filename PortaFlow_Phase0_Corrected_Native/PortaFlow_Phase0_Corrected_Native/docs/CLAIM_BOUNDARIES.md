# Claim Boundaries

## Safe to claim if the run completes

- The experiment executed equivalent deterministic continuations using three real framework runtimes.
- Certain information-transfer conditions preserved or violated predefined behavioral invariants in specific directed framework/workflow cases.
- Framework-native checkpoint/persistence artifacts were captured for inspection.

## Not safe to claim yet

- Universal agent migration is solved.
- Arbitrary mid-instruction migration is possible.
- Every framework pair is semantically incompatible.
- `native_semantic` is PortaFlow/PCC.
- The experiment proves statistical population-wide rates.
- LLM behavior has been evaluated.

## Proposal phrasing

Use: “preliminary native cross-runtime continuation experiment at controlled migration-safe boundaries.”

Avoid: “1,080 real migrations proved a 33% success rate.”
