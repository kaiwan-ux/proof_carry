# Proposal-ready experiment description

We freeze two minimal continuation representations discovered in prior experiments and evaluate them without retuning on ten previously unseen composite workflows. The new suite includes callback waits, multi-effect execution, quorum joins, first-success races, nested loop/branch/retry interactions, human-edited state, multi-step saga compensation, lease renewal, mixed idempotency, and threshold map-reduce. Each workflow is executed across all six directed migrations among LangGraph, CrewAI, and Microsoft Agent Framework. The hybrid mechanism stores only portable semantic history plus certified external-effect receipts and reconstructs other continuation semantics using a generic event interpreter and declarative static workflow specification. The explicit mechanism stores control frontier, pending obligations, effect receipts, and continuation contract directly. Technical failures, safe rejections, and unsafe continuations are reported separately.
