# Why v3 is stronger

1. The candidates are frozen before the new suite is evaluated.
2. None of the ten workflow names appeared in the discovery benchmark.
3. The inference engine is generic and contains no workflow-name conditionals.
4. Static workflow semantics are supplied declaratively, analogous to having the target program/graph definition available during migration.
5. Native target execution still occurs in LangGraph, CrewAI, and Microsoft Agent Framework.
6. Optional GPT-OSS-120B evaluation is separated from the deterministic framework experiment.
