# Optional GPT-OSS-120B robustness stage

The deterministic native matrix is primary evidence. The optional LLM stage tests planner interpretation under baseline, duplicate/noise, and out-of-order profiles only, because corrupted/contradictory evidence should usually be rejected before an LLM is asked to plan.

Model: `openai/gpt-oss-120b` via Groq. The API key is never stored in the package.
