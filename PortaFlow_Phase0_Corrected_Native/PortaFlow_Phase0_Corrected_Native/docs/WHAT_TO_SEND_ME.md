# What to send back for analysis

Zip and upload the complete `results/` directory after the script finishes. Do not delete technical failures, JSON captures, or raw CSV rows. The most important files are `native_cross_runtime_runs.csv`, `technical_failures.json`, `PROPOSAL_EVIDENCE_SUMMARY.md`, `probe_summary.json`, and the `native_sources/` + `native_targets/` directories.
