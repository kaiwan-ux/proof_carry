# Claim Boundaries

Allowed if supported by results:
- native checkpoint/source-capture + target-runtime continuation validation across the three pinned frameworks
- deterministic continuation safety for the seven benchmark families
- safe rejection under tested evidence ambiguity

Do not claim without additional work:
- universal agent interoperability
- arbitrary direct interchange of native checkpoint bytes
- official AAIF/CapLease superiority
- cryptographic certificate authenticity (trusted-witness assumption remains)
- LLM-agent quality or stochastic reasoning robustness
- full coverage of every built-in framework retry/parallel/HITL primitive
