# Claim Boundaries

A Revision B PASS would support only the following narrow claim:

> Frozen MCC v2 safely distinguishes certified committed/not-committed external-effect states and rejects indistinguishable ambiguous states for one real mid-execution effect/ack pattern across six directed pairs among LangGraph, CrewAI and Microsoft Agent Framework.

It would **not** by itself prove:

- universal agent-framework interoperability;
- correctness for retries, loops, parallel joins, compensation or callbacks;
- official AAIF or CapLease superiority;
- cryptographic trust of certificates;
- LLM-level behavioral equivalence;
- production scalability or performance.

Those require later experiments.
