# Proposal-Ready Preliminary Experiment Description

We designed a deterministic native cross-runtime continuation experiment to test whether the suspected PortaFlow problem exists before building the proposed mechanism. Three continuation-sensitive workflow patterns—retry recovery, pending human approval, and a committed external side effect—are implemented through LangGraph, CrewAI, and Microsoft Agent Framework. At a declared migration-safe boundary, the source runtime produces framework-native execution evidence. The remaining workflow is then executed by a different real target runtime using either ordinary application state, application state plus observable history, or a privileged native-semantic diagnostic representation. Six directed runtime pairs produce 18 core migration cases and 54 condition runs.

The primary outcome is Safe Continuation Rate under hard contracts: no replay of completed work, no repeated retry attempt, preservation of pending approval, no duplicate committed side effect, no skipped required step, and correct termination. Technical failures are separated from semantic failures. Because the cases are deterministic designed scenarios, results are reported descriptively rather than with pseudo-replicated confidence intervals. The privileged native-semantic condition is an upper bound used only to test whether sufficient information can in principle restore the continuation; it is not claimed as PortaFlow's contribution.
