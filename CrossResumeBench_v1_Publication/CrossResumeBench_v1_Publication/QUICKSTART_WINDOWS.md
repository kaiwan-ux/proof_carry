# Windows quick start
1. Extract the ZIP.
2. Open PowerShell in the folder.
3. Create/activate a Python 3.11/3.12 virtual environment if desired.
4. `pip install -r requirements.txt`
5. `Set-ExecutionPolicy -Scope Process Bypass`
6. `.\run_crossresumebench.ps1`
7. Upload `CrossResumeBench_v1_results.zip`.

No API key is needed.
